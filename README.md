## What this is

**GSoCDex** is a curated, mobile-first archive of accepted **Google Summer of Code** proposals — sourced from open community archives, presented with the gravitas the work deserves.

If you're applying to GSoC, the single highest-leverage thing you can do before writing your own proposal is **read accepted ones**. The community has already collected hundreds of them, but navigating GitHub folder trees on a phone is painful. GSoCDex fixes that.

- 🔍 **Instant search** — by title, contributor, organization, or technology. All client-side, no backend.
- 📑 **In-browser PDF preview** — read on your phone in seconds. No downloads, no auto-popups.
- 🏷️ **Auto-tagged** — every proposal classified by language, framework, and domain (lexical match against a curated vocabulary, **no AI**).
- 📅 **Year / org / tech browsing** — slice the archive any way you want.
- ✍️ **Editorial tips section** — proposal structure, mentor communication, common rejection reasons.
- ✉️ **Zero email collection** — no newsletter, no signup, ever. Anonymous Vercel Analytics is the only telemetry.
- 🆓 **Free + open source** — MIT licensed.

## Why I built this

Watched a lot of folks from my timeline get selected for GSoC this year. But I also watched strong contributors — people who shipped real PRs, knew the codebase — get rejected. The reason wasn't code. It was **the proposal** or how they communicated with mentors.

So this site exists so nobody fails next year for a reason that's fixable.

## 🛠️ Tech stack

- **Next.js 15** (App Router) — fully static SSG, 282 prerendered pages
- **React 19** + **TypeScript 5** (strict)
- **Tailwind CSS v4** with CSS-first design tokens (Editorial Art Catalog: alabaster, charcoal, burnished gold)
- **IBM Plex Serif** + **Inter** + **JetBrains Mono** via `next/font/google`
- **Framer Motion** for sophisticated hover and scroll motion
- **Lenis** for smooth-scroll lerp
- **Radix UI** primitives (Dialog, Popover, Sheet)
- **react-pdf** for in-browser preview (lazy-loaded, NOT in homepage bundle)
- **MiniSearch** for client-side lexical search
- **Vercel Analytics** for anonymous traffic counts
- **No backend** · **No DB** · **No auth** · **No AI**

## 📂 Project structure

```
gsocdex/
├── app/                   Next.js App Router
│   ├── (site)/            Marketing pages: /, /about, /tips, /submit, /contribute, /disclosures
│   ├── browse/            Filterable list view
│   ├── p/[year]/[org]/[slug]/   Individual proposal page
│   ├── year/[year]/       Year archive
│   ├── org/[slug]/        Org page
│   ├── tech/[slug]/       Tech tag page
│   ├── api/og/            Edge-runtime social preview generator
│   ├── manifest.ts        PWA manifest
│   ├── sitemap.ts         Auto-generated sitemap
│   └── globals.css        Design tokens (Editorial Art Catalog palette)
├── components/            UI: ProposalCard, PDFViewer, SearchPalette, Hoverable, …
├── data/
│   ├── proposals.json     ← auto-generated by `pnpm ingest`
│   ├── orgs.json          ← auto-generated by `pnpm ingest`
│   ├── tech-tags.json     curated controlled vocabulary
│   ├── sponsors.json      sponsor config (empty in OSS)
│   └── tips/*.mdx         editorial articles
├── lib/                   data loaders, schema, SEO helpers, format utilities
├── public/
│   ├── proposals/{year}/{org}/*.pdf    served as static files, inline content-disposition
│   ├── illustrations/gsoc-sun.svg      official GSoC sun mark (© Google LLC)
│   └── search-index.json               built at build time
└── scripts/
    ├── ingest.ts                 pulls PDFs from source repos and writes data/*.json
    ├── build-search-index.ts     generates the MiniSearch index
    └── verify.ts                 newsletter / trademark sweep
```

## 🚀 Run locally

```bash
# Requires Node 20+ and pnpm 9+
pnpm install
pnpm ingest         # clones source repos, builds data/proposals.json + public/proposals/
pnpm dev            # http://localhost:3000

# Production
pnpm build && pnpm start
```

Other scripts:

| Command | What |
|---|---|
| `pnpm typecheck` | strict TS check |
| `pnpm lint` | ESLint via `next/core-web-vitals` |
| `pnpm verify` | newsletter / trademark sweep — fails if banned tokens slip in |
| `pnpm format` | Prettier write |
| `pnpm build-search-index` | regenerate `/public/search-index.json` |

## 🤝 Contributing

We welcome PRs adding accepted proposals, fixing metadata, improving the UI, and writing new tips articles.

**See [CONTRIBUTING.md](./CONTRIBUTING.md) for full details on how to add your proposal.**

Quick path to add an accepted proposal:

1. Drop the PDF in `public/proposals/{year}/{Org}/{your-slug}.pdf`
2. Append your entry to `data/proposals.json` (schema in `lib/schema.ts`)
3. Run `pnpm build-search-index` and `pnpm build`
4. Open a PR using our template

For batch additions from a community archive: add the repo to `lib/constants.ts → SOURCE_REPOS`, run `pnpm ingest`, and PR the regenerated JSON.

## 🔒 Author rights & removal

If you authored a proposal indexed here and would like it removed, file a request via [our disclosures page](https://gsoc-dex.vercel.app/disclosures). We honour removals within **7 days**.

If a source repository is taken down or relicensed restrictively, we remove all proposals from that source within **14 days**.
