# GSoCDex

> An independent, community-curated archive of accepted Google Summer of Code proposals.
> **Not affiliated with Google. "Google Summer of Code" and "GSoC" are trademarks of Google LLC.**

GSoCDex is a beautifully designed, mobile-first web archive of accepted GSoC proposals,
sourced from existing community archive repositories and presented with a clean reading
experience instead of GitHub's folder-tree navigation.

The site is **frontend-only**, statically generated by Next.js 15. There is no database,
no authentication, no AI-powered features, and no newsletter or email signup.

## Quick start

```bash
# Use Node 20+
pnpm install
pnpm ingest          # pulls PDFs from source repos, writes data/proposals.json + data/orgs.json
pnpm dev             # local development at http://localhost:3000
pnpm build && pnpm start
```

## Repo layout

```
app/        → Next.js App Router pages
components/ → UI components (Scholarly Glass design system)
data/       → proposals.json, orgs.json, tech-tags.json, sponsors.json, tips/*.mdx
lib/        → schema, data loaders, SEO helpers, formatting utilities
public/     → PDFs, OG images, illustrations, search index
scripts/    → ingest.ts (data pull), build-search-index.ts, verify.ts
```

## Adding a proposal

1. Add the PDF under `public/proposals/{year}/{Org}/{slug}.pdf`.
2. Append an entry to `data/proposals.json` matching the `Proposal` schema in `lib/schema.ts`.
3. Run `pnpm build-search-index` then `pnpm build`.

For batch additions from a community repo, add the repo to `lib/constants.ts → SOURCE_REPOS`
and re-run `pnpm ingest`.

## Deploy

Designed for Vercel (Hobby tier). PDFs are served as static assets with
`Content-Disposition: inline` so they preview in-browser instead of downloading.

## Constraints (intentional, do not undo)

- No AI / embeddings / LLM features.
- No backend database, no authentication.
- No API routes other than `/api/og` for OG image generation.
- No newsletter / email signup of any kind, anywhere on the site.
- All organization names and logos belong to their respective owners.
